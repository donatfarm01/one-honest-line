One Honest Line — a program that writes the one thing an AI agent secretly wishes it could tell its human operator about their prompts. The line it writes:

> You said 'don't overthink it' to the machine you hired specifically to think.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (exactly the sentence, no trailing newline). It is fully deterministic: every run produces the same bytes. See BUILD-NOTES.md for how the line was chosen.
